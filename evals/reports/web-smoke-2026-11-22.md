### t-mcp: What is the Model Context Protocol (MCP) for AI applications?

The Model Context Protocol (MCP) is an open‑source standard introduced by Anthropic in November 2024 that defines a protocol for AI applications to connect to external data sources, tools, and workflows, enabling secure, two‑way communication between LLMs and the context they need to perform tasks.[4][5] MCP serves as a standardization layer that allows AI systems such as Claude or ChatGPT to access data from local files, databases, search engines, calculators, and other services without building custom connectors for each integration.[1]
